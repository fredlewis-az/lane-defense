# lane-defense

A space invaders type game, hosted on GitHub Pages.

- [Lane Defense](https://fredlewis-az.github.io/lane-defense/) — the current version
- [Lane Defense Classic](https://fredlewis-az.github.io/lane-defense/classic/) — a second version, closer to the 1978 arcade feel

Both games are self-contained HTML files. Each title screen links to the other.
