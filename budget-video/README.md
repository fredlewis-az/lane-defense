# Every Dollar Has a Job — explainer video

Headless Remotion project that renders a ~90s motion-graphics explainer for young adults.

## Regenerate

```bash
npm install
npm run generate:audio   # edge-tts → public/audio/
npm run render           # → out/every-dollar-has-a-job.mp4
```

Voice: `en-US-AndrewNeural` (see `public/audio/durations.json`).

Output: 1920×1080, 30fps, H.264 + AAC.
